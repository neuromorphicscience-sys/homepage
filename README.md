# 山东大学科技成果转化收入分配计算器

这是一个面向山东大学老师、成果负责人、科研秘书、二级单位和科研院工作人员的科技成果转化现金收益分配测算工具。

系统为纯前端公网演示版，不接入学校财务系统、科研管理系统、OA 系统，不做登录、不做权限控制、不保存真实项目数据、不连接数据库。

## 产品定位

- 快速测算科技成果转化现金到账后的收益分配结果。
- 支持合同金额、本次到账金额、分期到账、成本扣除、转化方式、山东省内实施奖励修正等核心输入。
- 结果仅用于测算辅助、政策解释和复核参考，不作为正式财务入账结果。
- 支持打印 / 导出 PDF、导出 JSON、导出 CSV、复制文本。

免责声明：

> 本系统为山东大学科技成果转化收入分配测算工具，计算结果仅供成果负责人、二级单位、科研院和财务部复核参考，正式分配以学校审核意见和财务入账结果为准。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址，通常为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

构建产物位于 `dist/`，可部署到 GitHub Pages、Vercel 或 Netlify。

## 部署到 GitHub Pages

项目已包含 `.github/workflows/pages.yml`。

1. 推送代码到 GitHub 仓库的 `main` 分支。
2. 打开仓库 Settings → Pages。
3. 在 Build and deployment 中，Source 选择 GitHub Actions。
4. 后续 push 到 `main` 后会自动执行 `npm ci`、`npm run build`，并发布 `dist/`。

## 部署到 Vercel

1. 在 Vercel 新建项目并导入 GitHub 仓库。
2. Framework Preset 选择 Vite。
3. Build Command 使用 `npm run build`。
4. Output Directory 使用 `dist`。
5. 保存并部署。

## 计算规则说明

金额阈值全部按“元”理解，内部按“分”进行整数计算。

阶梯区间：

- T1：0 - 10,000,000
- T2：10,000,000 - 50,000,000
- T3：50,000,000 - 100,000,000
- T4：100,000,000 - 500,000,000
- T5：超过 500,000,000

转让所有权比例：

- T1：团队 80%，二级单位 9%，学校基金 6%，专项基金 5%
- T2：团队 82%，二级单位 7%，学校基金 6%，专项基金 5%
- T3：团队 85%，二级单位 6%，学校基金 5%，专项基金 4%
- T4：团队 87%，二级单位 5%，学校基金 5%，专项基金 3%
- T5：团队 90%，二级单位 4%，学校基金 4%，专项基金 2%

许可比例：

- T1：团队 85%，二级单位 6%，学校基金 5%，专项基金 4%
- T2：团队 87%，二级单位 6%，学校基金 4%，专项基金 3%
- T3：团队 90%，二级单位 4%，学校基金 4%，专项基金 2%
- T4：团队 92%，二级单位 3%，学校基金 3%，专项基金 2%
- T5：团队 95%，二级单位 2%，学校基金 2%，专项基金 1%

系统统一采用合同额加权阶梯分配算法：先根据合同总金额计算各阶梯切片占比，再将本次可分配净收益按该占比分摊到各阶梯区间，并分别适用对应分配比例。

山东省内实施奖励修正：

- 团队调增净收益的 2%
- 二级单位调减净收益的 1%
- 学校基金调减净收益的 0.5%
- 科技成果转化专项基金调减净收益的 0.5%

若四舍五入产生尾差，第一版默认调整到科技成果转化专项基金，并在页面展示尾差调整金额。

## 成本首次进账集中扣除口径

已确认口径：成本扣除采用“首次进账集中扣除”。

- 如果“本次前累计到账金额 = 0”，判定为首次进账。
- 首次进账时，本次成本合计 = 专利费用 + 业务成本 + 税款 + 评估费 + 技术经理人咨询服务费 + 其他开支。
- 首次进账时，本次可分配净收益 = 本次到账金额 - 本次成本合计。
- 如果“本次前累计到账金额 > 0”，判定为后续进账。
- 后续进账时，本次成本合计 = 0，本次可分配净收益 = 本次到账金额。
- 首次进账成本合计超过本次到账金额时，系统禁止生成正式分配结果。

- 学校基金最终金额：583,333.33 元
- 科技成果转化专项基金最终金额：443,333.33 元
- 合计：14,000,000.00 元

### 后续进账示例

- 合同金额：15,000,000 元
- 转化方式：许可
- 本次前累计到账金额：5,000,000 元
- 本次到账金额：3,000,000 元
- 是否山东省内实施：是
- 本次成本合计：0 元
- 本次可分配净收益：3,000,000 元

系统会提示：

> 当前为后续进账，既有成本已在首次进账时集中扣除，本次默认不再扣除成本。
