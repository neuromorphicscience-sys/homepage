# 山东大学科技成果转化现金收益分配计算器

这是一个面向山东大学老师、成果负责人、科研秘书、二级单位和科研院工作人员的科技成果转化现金收益分配测算工具。

系统为纯前端公网演示版，不接入学校财务系统、科研管理系统、OA 系统，不做登录、不做权限控制、不保存真实项目数据、不连接数据库。

## 产品定位

- 快速测算科技成果转化现金到账后的收益分配结果。
- 支持合同金额、本次到账现金、分期到账、成本扣除、转化方式、山东省内实施奖励修正等核心输入。
- 结果仅用于测算辅助、政策解释和复核参考，不作为正式财务入账结果。
- 支持打印 / 导出 PDF、导出 Excel、复制文本。

免责声明：

> 本计算器仅用于成果转化收益分配测算，正式分配以最终审核和入账结果为准。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址，通常为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

构建产物位于 `dist/`，可部署到 GitHub Pages、Vercel 或 Netlify。

## 部署到 GitHub Pages

项目已包含 `.github/workflows/pages.yml`。

1. 推送代码到 GitHub 仓库的 `main` 分支。
2. 打开仓库 Settings → Pages。
3. 在 Build and deployment 中，Source 选择 GitHub Actions。
4. 后续 push 到 `main` 后会自动执行 `npm ci`、`npm run build`，并发布 `dist/`。

## 部署到 Vercel

1. 在 Vercel 新建项目并导入 GitHub 仓库。
2. Framework Preset 选择 Vite。
3. Build Command 使用 `npm run build`。
4. Output Directory 使用 `dist`。
5. 保存并部署。

## 计算规则说明

页面金额录入单位统一为“元”，输入框下方辅助显示“折合：X.XX 万元”。辅助折合万元仅用于展示，不参与计算。金额阈值和展示结果按“元”理解，内部按“分”进行整数计算。

阶梯区间：

- T1：0 - 10,000,000
- T2：10,000,000 - 50,000,000
- T3：50,000,000 - 100,000,000
- T4：100,000,000 - 500,000,000
- T5：超过 500,000,000

转让所有权比例：

- T1：奖励成果完成人收益 80%，二级单位科研发展基金 9%，学校基金 6%，科技成果转化专项基金 5%
- T2：奖励成果完成人收益 82%，二级单位科研发展基金 7%，学校基金 6%，科技成果转化专项基金 5%
- T3：奖励成果完成人收益 85%，二级单位科研发展基金 6%，学校基金 5%，科技成果转化专项基金 4%
- T4：奖励成果完成人收益 87%，二级单位科研发展基金 5%，学校基金 5%，科技成果转化专项基金 3%
- T5：奖励成果完成人收益 90%，二级单位科研发展基金 4%，学校基金 4%，科技成果转化专项基金 2%

许可比例：

- T1：奖励成果完成人收益 85%，二级单位科研发展基金 6%，学校基金 5%，科技成果转化专项基金 4%
- T2：奖励成果完成人收益 87%，二级单位科研发展基金 6%，学校基金 4%，科技成果转化专项基金 3%
- T3：奖励成果完成人收益 90%，二级单位科研发展基金 4%，学校基金 4%，科技成果转化专项基金 2%
- T4：奖励成果完成人收益 92%，二级单位科研发展基金 3%，学校基金 3%，科技成果转化专项基金 2%
- T5：奖励成果完成人收益 95%，二级单位科研发展基金 2%，学校基金 2%，科技成果转化专项基金 1%

系统统一采用合同额加权阶梯分配算法：先根据合同总金额计算各阶梯切片占比，再将本次可分配净收益按该占比分摊到各阶梯区间，并分别适用对应分配比例。

山东省内实施奖励修正：

- 团队调增净收益的 2%
- 二级单位调减净收益的 1%
- 学校基金调减净收益的 0.5%
- 科技成果转化专项基金调减净收益的 0.5%

测算结果按“学校部分”和“成果完成人部分”展示。学校部分包含学校基金、科技成果转化专项基金、二级单位科研发展基金；成果完成人部分包含奖励成果完成人收益、成本补偿至成果完成人科研发展基金、成本补偿至个人。若四舍五入产生尾差，统一计入成果完成人科研发展基金。

## 成本首次进账集中扣除口径

成本扣除采用首次到账集中扣除的方式。

- 如果“本次前累计到账金额 = 0”，判定为首次进账。
- 首次进账时，本次成本扣除合计 = 2 × 个人承担专利费用 + 科研经费及发展基金支出 + 税费 + 评估费 + 其他成本。
- 首次进账时，本次可分配净收益 = 本次到账现金 - 本次成本扣除合计。
- 个人承担专利费用双倍扣除：其中一份补偿给发明人个人，另一份补偿至发明人科研发展基金；科研经费及发展基金支出补偿至成果完成人科研发展基金；其他成本仅作成本扣除。完成成本扣除后，再对本次可分配净收益按比例分配。
- 如果“本次前累计到账金额 > 0”，判定为后续进账。
- 后续进账时，本次成本扣除合计 = 0，本次可分配净收益 = 本次到账现金。
- 首次进账成本合计超过本次到账现金时，系统禁止生成正式分配结果。
